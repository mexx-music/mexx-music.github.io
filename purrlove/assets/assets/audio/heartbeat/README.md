# Heartbeat Sounds

Lege hier deine Herzton-Audiodateien ab.

## Empfohlene Formate
| Format | Empfehlung |
|--------|-----------|
| .mp3   | ✅ Beste Wahl – klein, überall kompatibel |
| .m4a   | ✅ Sehr gut – besonders auf iOS/macOS |
| .wav   | ✅ Funktioniert – aber größere Dateigröße |
| .ogg   | ⚠️  Nur Android/Web, nicht auf iOS |

## Dateinamen (werden in dieser Reihenfolge gesucht)
1. heartbeat1.mp3 / heartbeat1.m4a / heartbeat1.wav
2. heartbeat.mp3  / heartbeat.m4a  / heartbeat.wav
3. heart.mp3      / heart.m4a      / heart.wav
4. lub-dub.mp3    / lub-dub.m4a    / lub-dub.wav

Wenn keine Datei gefunden wird, generiert die App automatisch
einen synthetischen Herzton (kein Fehler).

## Beispiel
Kopiere z.B.:
  heartbeat1.mp3  →  assets/audio/heartbeat/heartbeat1.mp3
und starte die App neu – sie wird automatisch verwendet.
